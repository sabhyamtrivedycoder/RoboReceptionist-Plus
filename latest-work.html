A granular breakdown of the mathematical image transformations, spatial convolution kernels, and deterministic clinical classification pipelines powering Robo Receptionist +.

01 // TISSUE CHROMINANCE PROFILING

HSV Dual-Hue Erythema Extravasation

Standard RGB color channels are hypersensitive to hospital lighting flicker and skin tone variances. Our vision engine converts ingested frames into the HSV (Hue, Saturation, Value) cylindrical manifold, applying a dual-band hue segmentation mask to quantify vascular erythema extravasation:

// Mathematical Hue Range Segmentation

Hue Range 1: 0 ≤ H ≤ 10   (Primary Red Spectrum)

Hue Range 2: 160 ≤ H ≤ 180 (Deep Crimson Spectrum)

Saturation Filter: S ≥ 40, Value Filter: V ≥ 35

R_index = (N_erythema_pixels / N_total_roi_pixels) * 100%

When R_index ≥ 16.0% with low edge discontinuity, the system triggers high-suspicion thermal scald logic. When accompanied by sharp structural discontinuities, it escalates to active capillary hemorrhage.

02 // STRUCTURAL CONTINUITY

3x3 Sobel Spatial Gradient Kernel

To distinguish blunt contusions from deep lacerations requiring immediate debridement and primary closure, the system convolves a pair of orthogonal 3x3 derivative filters:

// Horizontal & Vertical Convolution Kernels

K_x = [[-1, 0, +1], [-2, 0, +2], [-1, 0, +1]]

K_y = [[-1, -2, -1], [ 0, 0, 0], [+1, +2, +1]]

Gradient Magnitude: G = sqrt(G_x^2 + G_y^2)

Edge Density Score: Density = (Count(G ≥ Threshold) / ROI_Area) * 100%

Deep open lacerations generate high gradient spikes (Density ≥ 7.8%) along linear fault trajectories, whereas superficial hematomas exhibit diffuse low-gradient boundaries.

03 // CLINICAL STRATIFICATION

Emergency Severity Index (ESI v4) Mapping

The Emergency Severity Index is an internationally validated five-tier emergency triage algorithm. Robo Receptionist + translates quantitative optical indices into deterministic ESI tiers:

ESI Level 1 · Immediate Resuscitation Active arterial extravasation, severe periorbital penetrating trauma, or extensive partial/full-thickness burns. Immediate trauma bay prep.
ESI Level 2 · Emergent / High Risk Deep full-thickness lacerations requiring primary closure < 30 min, extensive second-degree scalds, or compound fracture deformities.
ESI Level 3 · Urgent / Stable Closed limb deformities requiring multiple resources (X-ray, orthopedic reduction), moderate soft-tissue contusions.
ESI Level 4 & 5 · Semi-Urgent / Non-Urgent Superficial abrasions, minor ecchymosis without structural breach. Directed to fast-track ambulatory care.
